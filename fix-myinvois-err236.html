LHDN MyInvois Troubleshooting

How to Fix MyInvois Error ERR236 & MYI-L10 on Batch Uploads

1. Cause & Fix for Error ERR236

LHDN's validator throws ERR236 whenever there is a mismatch between the General Public Buyer TIN and the Line Item Classification Code:

  • If Buyer TIN is EI00000000010 on a consolidated B2C e-Invoice, every single line item must use Classification Code 004 (not 022).
  • Buyer Registration Number, SST Number, Address, and Contact Number must be populated with literal NA (empty cells trigger schema rejection).
  • Conversely, if a single receipt exceeds RM 10,000.00, you cannot use 004 consolidated filing.

2. Cause & Fix for Error MYI-L10 & TaxType E

  • Missing 0.00 TaxSubtotal (MYI-L10): Non-SST registered SMEs use TaxType 06 (Not Applicable). Marketplace CSVs leave Tax Amount blank, which omits the required 0.00 tax node. Explicitly set TaxType 06 with Tax Amount 0.00.
  • Missing Exemption Reason on TaxType E: Whenever TaxType is E (Tax Exempt), LHDN requires a non-empty TaxExemptionReason string.
