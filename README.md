# Shopee, Lazada & POS to LHDN MyInvois Converter (Malaysia SME Tool)

**Live App (Full-Screen, Zero Data Storage):** https://hyperfetch-tools.github.io/myinvois/

Turn messy **Shopee MY, Lazada, TikTok Shop, or Retail POS order CSVs** into official **LHDN MyInvois 11-Sheet Excel (`.xls`) & UBL 2.1 XML** files in 30 seconds—before the **7th of every month** consolidated filing deadline.

### How It Works in 3 Steps:
1. **Export Monthly Orders:** In Shopee Seller Centre → *My Orders → Export* (or Lazada / TikTok Shop / POS CSV).
2. **Drop File & Preview in Browser:** Error audit & diff preview run directly in your browser; final export compiles in stateless RAM (zero database storage). Auto-fills General Public TIN (`EI00000000010`), Classification `004`, MSIC `47912` (Online Retail), ISO dates (`YYYY-MM-DD`), and separates orders above `RM 10,000`.
3. **Upload Straight to MyInvois:** Download the ready-to-submit 11-Sheet Excel (`.xls`) or UBL 2.1 `.xml` file and upload at `myinvois.hasil.gov.my`.
